# Third-party inspirations

`hstack` is original package text and structure informed by two MIT-licensed sources:

1. **Skills for Real Engineers** by Matt Pocock. Patterns carried forward conceptually include planning before implementation, domain modeling, TDD, code review, repository investigation, issue-driven decomposition, and handoff discipline.
2. **pstack** by Lauren Tan / Cursor. Patterns carried forward conceptually include a default rigor mode, explicit playbook routing, adversarial multi-agent review, runtime proof, blast-radius thinking, verification skills, and turning repeated lessons into reusable structure.

This package intentionally does not vendor or mirror either source. It adapts the ideas to evidence-first agentic systems, market infrastructure, local Windows/WSL verification, and clean-room architecture work.

The parent repository is MIT licensed. Consult the upstream repositories for their original licenses and attribution.
